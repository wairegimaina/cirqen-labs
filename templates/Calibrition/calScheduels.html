What the Smart Organiser does Current logic: {% if current_planning_logic == 'date_based' or current_planning_logic == 'department' %} Department-Based {% elif current_planning_logic == 'description_based' or current_planning_logic == 'description' %} Description-Based {% else %} Not set {% endif %}

The Smart Organiser scans all pending and pushed schedules and redistributes them across the calendar so equipment that belongs to the same group lands in the same month. Use it after switching planning logic, or whenever the schedule has drifted out of alignment.

1
Groups are identified — either by department (Dept-Based) or by equipment type (Desc-Based), depending on the logic you select below.
2
Months are assigned — groups are spread evenly from the start month you choose, rotating through the year so no month is overloaded.
3
Protected schedules are skipped — completed, locked, and signal-created (PPM) schedules are never touched, preserving calibration intervals and audit trails.
Tick Dry Run to preview which schedules would move without saving any changes.
