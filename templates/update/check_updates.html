How to build an update package

On your development machine, run build_update.py from the project root after making your changes. It produces a .zip file ready to upload here.

# On your dev laptop
# 1. Make your code changes and test them locally
# 2. Run the build script (adjust the version)
python build_update.py --version 1.3.1 --changes "Fixed PPM bug, added export"
# 3. Optional: mark as critical
python build_update.py --version 1.3.1 --critical --changes "Security fix"
# 4. The script outputs:
# Built: equiper_update_v1.3.1.zip (3.2 MB)
# SHA-256: abcdef1234567890…
# 5. Transfer the .zip to the server via USB/SCP/SFTP
# 6. Upload it here using the form above
# 7. Click "Apply"
